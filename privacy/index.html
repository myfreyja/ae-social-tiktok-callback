Privacy Policy

AE Social Publisher is a local desktop workflow tool. It uses platform authorization only to connect accounts selected by the user and to upload user-selected video content.

Access tokens and app credentials are stored locally on the user's computer by the desktop helper. This website does not store social media tokens, passwords, uploaded videos, captions, or personal profile data.

The TikTok callback page only forwards OAuth authorization responses to the local desktop helper running on the user's machine.

Users may remove saved credentials and connected account tokens from the desktop panel by using Clean Auth Data.
